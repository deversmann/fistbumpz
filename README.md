# fistbumpz E-Sports Team

Official website for the fistbumpz e-sports team.

## 🎮 About

Single-page website showcasing our team, players, and social media presence. Built with pure HTML/CSS/JS for simplicity and performance.

## 🚀 Quick Start

Just open `index.html` in your browser - no build process required!

## 📦 Hosting on GitHub Pages

1. Create a new repository on GitHub
2. Push this code:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/fistbumpz.git
   git branch -M main
   git push -u origin main
   ```
3. Go to Settings → Pages
4. Set source to "Deploy from a branch" 
5. Select `main` branch and `/ (root)` folder
6. Save and wait for deployment

Your site will be live at: `https://YOUR_USERNAME.github.io/fistbumpz/`

## ✏️ Customization

### Update Team Members
Edit the roster section in `index.html` to add/remove/modify player cards.

### Change Colors
Modify CSS variables at the top of the `<style>` section:
```css
:root {
    --accent-primary: #7c3aed;
    --accent-secondary: #3b82f6;
}
```

### Update Social Links
Replace `href="#"` with your actual social media URLs in the social section.

### Add Your Logo
Replace the text "fistbumpz" in the hero section with an `<img>` tag pointing to your logo file.
